## 构建场景BVH

BVH(Bounding Volume Hierarchy)是一种高效的空间划分数据结构，应用于光线追踪、碰撞检测、视锥剔除；

### 构建BVH

1. 核心思想：BVH通过递归地将场景物体分组，并为每组计算一个包围盒，形成一个树状结构；从根节点到叶节点包围盒逐渐变小，且更紧密的包围物体；

2. 构建流程

   - 选择所有纳入的几何体
   - 计算整个场景的全局包围盒
   - 递归分割物体集合
   - 为每个节点计算包围盒
   - 构建树结构

3. BVH节点数据结构

   ```c++
   struct BVHNode {
       AABB bbox;          // 该节点的轴对齐包围盒
       BVHNode* left;      // 左子节点
       BVHNode* right;     // 右子节点
       int startPrimitive; // 起始图元索引（叶子节点）
       int endPrimitive;   // 结束图元索引（叶子节点）
       bool isLeaf;        // 是否为叶子节点
   };
   ```
