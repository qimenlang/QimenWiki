核的设计本质上就是设计这一组权重值。这组权重的数值、排列和总和，决定了滤波器的行为。核作为一种“加权平均”或“差异放大器”

1. **权重之和（Sum of Weights）**：这是最关键的特性之一。
   - **和 = 1**：这意味着操作不会改变图像的整体亮度水平。平坦区域的输出值大致等于输入值。这是**平滑/模糊**和**锐化**核的特征。
   - **和 = 0**：这意味着在平坦区域（所有像素值相同），输出为0（黑色）。它只对**变化**的区域有响应，用于**边缘检测**和**高通滤波**。
   - **和 > 1**：会增加图像的整体亮度。
2. **权重的分布（Distribution of Weights）**：权重在空间上的分布决定了核的敏感方向和行为。
   - **各向同性（Isotropic）**：权重分布是对称的（如高斯模糊核），对所有方向的响应相同。
   - **各向异性（Anisotropic）**：权重分布不对称（如Sobel、Prewitt算子），对特定方向（水平、垂直、对角线）的变化特别敏感。

#### 1. 平滑/模糊滤波器（低通滤波）

- **目标**：消除噪声，平滑细节，实现模糊效果。

- **原理**：让每个像素的值与其周围像素的值更接近。通过“平均化”或“加权平均”来减少像素间的剧烈变化。

- **代表核**：

  - **均值模糊**：所有权重相等且和为1。

    text

    ```
    [1/9, 1/9, 1/9]
    [1/9, 1/9, 1/9]
    [1/9, 1/9, 1/9]
    ```

  - **高斯模糊**：权重服从二维高斯分布，中心权重最大，越往外权重越小。这是一种更符合人眼感知的平滑，效果更自然。

    text

    ```
    [1/16, 2/16, 1/16]
    [2/16, 4/16, 2/16]
    [1/16, 2/16, 1/16]
    ```

#### 2. 锐化滤波器（高通滤波）

- **目标**：增强边缘和细节，让图像看起来更清晰。**锐化的核心思想是“增强差异”**。

- **原理**：**强化像素与其周边像素的差异**。如前一个问题所述，其设计基于“原始图像 + 边缘信息”的思想。

- **代表核**：

  - **拉普拉斯锐化**：中心为正，周围为负，总和为1。

    text

    ```
    [ 0, -1,  0]
    [-1,  5, -1]
    [ 0, -1,  0]
    ```

    (这实际上是 `原始图像 + 拉普拉斯边缘图像`)

#### 3. 边缘检测滤波器（高通滤波的特化）

- **目标**：突出显示灰度剧烈变化的区域（边缘）。

- **原理**：对**梯度**（变化率）进行建模。在平坦区域，梯度为0（输出黑色）；在变化剧烈的边缘，梯度很大（输出亮色）。

- **代表核**：

  - **Sobel算子**：总和为0，具有方向性（检测水平或垂直边缘）。

    - Sobel X (检测垂直边缘):

      text

      ```
      [-1, 0, 1]
      [-2, 0, 2]
      [-1, 0, 1]
      ```

    - Sobel Y (检测水平边缘):

      text

      ```
      [-1, -2, -1]
      [ 0,  0,  0]
      [ 1,  2,  1]
      ```

#### 4. 浮雕（Emboss）滤波器

- **目标**：产生一种3D浮雕效果。

- **原理**：本质也是一种方向性的边缘检测，但**核的总和通常为1**（而不是0），这意味着它会为结果添加一个恒定的偏移量（通常是127或128），使其呈现灰色背景，从而产生光影效果。

- **代表核**（西北方向浮雕）：

  text

  ```
  [-2, -1,  0]
  [-1,  1,  1]
  [ 0,  1,  2]
  ```

  (总和为1，输出结果会加上128的灰度值，使非边缘区域呈中性灰色)。

#### 5. 低通滤波 vs. 高通滤波

- **低通滤波（Low-pass Filtering）**
  - **目的**：**允许**低频信号（平缓变化）**通过**，**阻挡**高频信号（快速变化）。
  - **结果**：图像变得**平滑、模糊**。因为边缘（高频）被抑制了，剩下的主要是大块的平坦区域（低频）。
  - **调音台比喻**：调低高音，提升低音，声音变得低沉、浑厚。
- **高通滤波（High-pass Filtering）**
  - **目的**：**允许**高频信号（快速变化）**通过**，**阻挡**低频信号（平缓变化）。
  - **结果**：图像只剩下**边缘和纹理**等细节，平坦区域则变得暗淡甚至黑色。
  - **调音台比喻**：调高低音，提升高音，声音变得尖锐、刺耳。
