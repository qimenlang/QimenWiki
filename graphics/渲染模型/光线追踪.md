### 一、Ray Tracing（光线追踪）原理

光线追踪是一种模拟光线在场景中传播的渲染技术，其核心思想是**逆向追光**。因为从光源发出的大量光线中，只有极少部分能最终进入人眼，正向模拟效率极低。所以，光线追踪反其道而行之：

**“从人眼（摄像机）出发，反向追踪每一条光线，看它最终会‘碰到’什么，从而决定屏幕上每个像素的颜色。”**

#### 路径追踪

1. 单向路径追踪：从**相机出发**，向场景中发射光线，通过随机采样在场景中"游走"，直到击中光源或达到终止条件。
   - **焦散效果差**：难以有效采样从光源到镜面再到漫反射表面的路径
   - **小光源问题**：当光源很小时，找到从相机到光源的路径概率很低
2. 双向路径追踪：**同时从相机和光源出发**构建子路径，然后将它们连接起来形成完整的光传输路径，可以解决小光源和焦散差的问题；

#### 核心步骤（以最简单的 Whitted 风格光线追踪为例）：

想象一个虚拟的相机和一个3D场景，场景中有物体和光源。

1.  **生成初始光线（Primary Ray）**
    
    *   对于屏幕上（或最终图像上）的每一个像素，从相机位置发出一条光线，穿过这个像素对应的虚拟小孔。
    *   这条光线被称为“主光线”或“初始光线”。
    
2.  **求交测试（Ray-Object Intersection）**
    
    *   计算这条光线与场景中的所有物体的交点。

    *   通过数学方法（如求解射线与球体、三角形的方程）找到最近的、有效的交点。这一步是光线追踪中计算量最大的部分。
    
    *   ##### 光线与三角形（Triangle）的求交
    
        三角形是图形学中最重要的几何元。求交测试方法主要有两种：**几何法**和**重心坐标法**。最著名、最高效的算法是 **Möller–Trumbore 算法**，它属于重心坐标法。
    
        一个三角形由三个顶点 `V₀, V₁, V₂` 定义。
    
        **Möller–Trumbore 算法（1997）**
        该算法的优点是不需要预计算三角形的平面方程，直接一步得到交点和其重心坐标。
    
        **1. 思路：**
        光线方程：`O + tD`
        三角形内的任意一点 `P` 可以用重心坐标 `(u, v)` 表示：
        `P = (1 - u - v)V₀ + u V₁ + v V₂`
    
        **2. 联立方程：**
        `O + tD = (1 - u - v)V₀ + u V₁ + v V₂`
    
        可以 rearranged 为：
        `O - V₀ = u (V₁ - V₀) + v (V₂ - V₀) - tD`
    
        **3. 用矩阵形式表示：**
        这是一个关于 `t, u, v` 的线性方程 ，可以用矩阵和向量表示为：
    
        text
    
        ```
        [ -D, (V₁ - V₀), (V₂ - V₀) ] [ t, u, v ]ᵀ = O - V₀
        ```
    
        （`ᵀ` 表示转置）
    
        **4. 克莱姆法则（Cramer's Rule）求解：**
        算法利用克莱姆法则来高效地求解这个方程组。它定义了几个辅助向量：
        `E1 = V1 - V0`
        `E2 = V2 - V0`
        `T = O - V0`
        `P = D × E2` // × 表示叉积
        `Q = T × E1`
    
        然后计算：
        `det = P · E1` // 矩阵的行列式
    
        如果 `det` 接近于 0，说明光线与三角形平面平行，没有交点。
        然后计算：
        `t = (Q · E2) / det`
        `u = (P · T) / det`
        `v = (Q · D) / det`
    
        **5. 有效性检验：**
        最终，一个有效的交点必须满足以下所有条件：
    
        - `t > 0` （交点在光线正方向上）
        - `u >= 0`
        - `v >= 0`
        - `(u + v) <= 1` （保证点在三角形内部）
    
    * 一个复杂的场景可能有数百万甚至数十亿个三角形。如果一条光线需要与场景中的**每一个**物体都做一次求交测试，计算量是完全无法承受的。因此，必须进行优化。**核心优化策略：Bounding Volume Hierarchy (BVH) - 包围层次结构**
    
3.  **着色计算（Shading）**
    
    *   找到了一个交点后，就需要计算这个点看起来是什么颜色。
    *   这通常包括：
        *   **直接光照：** 检查这个点是否**直接**被光源照亮。从交点向光源再发出一条光线（称为**阴影光线 Shadow Ray**）。如果这条阴影光线在到达光源前没有被任何物体阻挡，那么这个点就被该光源照亮，计算其漫反射和高光颜色。
        *   **间接光照：** 模拟光线在物体之间的反弹。这是光线追踪产生逼真效果的关键。
    
4.  **递归追踪（Recursive Tracing）**
    
    *   为了模拟**反射**：在交点处，根据物体表面的材质属性（如金属度），生成一条**反射光线（Reflection Ray）**。然后递归地对该反射光线重复步骤2和3，将返回的颜色值叠加到当前交点的颜色上。
    *   为了模拟**折射**：如果物体是透明的（如玻璃、水），则生成一条**折射光线（Refraction Ray）**，并同样递归地追踪它，将返回的颜色值叠加进来。
    *   递归需要设置一个最大深度（如5次），以防止无限循环。
    
5.  **终止条件**
    
    *   光线击中了光源 -> 返回光源颜色。
    *   光线什么都没有击中 -> 返回背景色（如黑色）。
    *   光线递归深度达到上限 -> 停止追踪，返回当前累计的颜色。

#### 优点：
*   **极高的真实感**：能物理正确地模拟反射、折射、软阴影、焦散、全局光照等复杂光学现象。
*   **算法直观**：其原理非常符合人类对光线的直观理解。

#### 缺点：
*   **计算开销巨大**：每条光线都需要与场景中所有物体求交，递归追踪又会使光线数量指数级增长。传统上是离线渲染技术（用于电影特效），但随着硬件发展（如NVIDIA RTX显卡的专用光追核心），实时光线追踪已成为可能。

### 二、Ray Marching（光线步进）原理

Ray Marching 是另一种渲染技术，它与传统基于多边形网格（Mesh）的光线追踪不同，特别**适合渲染没有明确几何定义的隐式表面（通过数学函数定义）和体积**。

它的核心思想是：**“小步快跑，逐步逼近”**。

#### 核心步骤：

1.  **生成初始光线**
    *   这一步和传统光线追踪一样，从相机向每个像素发射一条光线。

2.  **沿光线步进（Marching）**
    *   不像光线追踪那样直接求解精确的交点，Ray Marching 是沿着光线方向，一步一步地前进。
    *   在每一步，都有一个当前采样点 `P`。

3.  **距离场查询（SDF - Signed Distance Field）**
    *   场景中的几何形状由一个特殊的函数 `SDF(p)` 定义。这个函数接收一个空间坐标点 `p`，返回这个点到**最近物体表面的带符号距离**。
    *   **正数**：点在物体外部。
    *   **负数**：点在物体内部。
    *   **零**：点在物体表面上。
    *   这个 `SDF` 函数是 Ray Marching 的灵魂。

4.  **安全前进**
    *   在当前位置 `P`，查询 `SDF(P)`，得到一个距离值 `d`。
    *   这个值 `d` 代表：以 `P` 为球心，半径为 `d` 的球体内**绝对没有任何物体表面**。这是一个“安全距离”。
    *   因此，我们可以放心地沿着光线方向至少前进 `d` 的距离，而不会错过任何交点。

5.  **判断命中**
    *   将当前点 `P` 向前移动 `d` 的距离。
    *   重复步骤3和4。
    *   **循环终止条件1（命中表面）**：如果 `d` 的值小于一个非常小的阈值（如 `0.0001`），我们就认为已经非常接近物体表面了，可以判定为命中。
    *   **循环终止条件2（未命中）**：如果光线前进的总距离已经超过一个预设的最大值（比如场景的远平面），则认为这条光线什么也没击中。

6.  **着色**
    *   一旦命中，就可以像光线追踪一样，计算法线（通过对 `SDF` 函数求梯度近似得到）、光照、阴影等。

#### 应用场景：

​	引擎会先渲染传统几何，然后在后期处理（Post-Processing）阶段，通过计算着色器，对需要添加SDF效果的区域执行Ray Marching。

#### 优点：
*   **无限细节**：几何由数学函数定义，理论上可以无限放大而不出现像素感。
*   **易于构造复杂几何**：通过 `SDF` 的并集、交集、差值等操作，可以轻松创建极其复杂的“雕塑式”模型。
*   **天然适合体积渲染**：非常适合渲染云、烟雾、火焰等没有明确表面的物体。

#### 缺点：
*   **性能开销不稳定**：每一步都需要计算 `SDF` 函数，如果函数复杂或步进次数多，计算量会很大。
*   **精度与性能的权衡**：步长太小，计算慢；步长太大，容易错过细节或穿透薄物体。

### 总结与对比

| 特性         | Ray Tracing（光线追踪）                            | Ray Marching（光线步进）                                     |
| :----------- | :------------------------------------------------- | :----------------------------------------------------------- |
| **核心思想** | **逆向追踪，精确求交**                             | **沿光线步进，安全距离探索**                                 |
| **几何表示** | **显式几何**（三角形网格、曲面）                   | **隐式几何**（Signed Distance Field - SDF）                  |
| **求交方式** | 求解光线与物体的数学方程，一步到位                 | 逐步迭代，多次查询SDF函数                                    |
| **主要应用** | 电影级渲染、实时游戏光照（反射、阴影）、建筑可视化 | **体渲染**（云、烟、火）、**SDF建模**（DemoScene、ShaderToy常见）、程序化生成的内容 |
| **优点**     | 真实感极强，算法直观                               | 无限细节，易于构造复杂形状，天然适合体积                     |
| **缺点**     | 计算量大，求交计算复杂                             | 性能开销不稳定，有步进误差                                   |

希望这个详细的解释能帮助您完全理解 Ray Tracing 的原理，并厘清了 Ray Matching 的疑惑。现在您也知道了另一种强大的图形学技术——Ray Marching。
