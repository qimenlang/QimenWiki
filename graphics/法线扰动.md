**更物理准确的扰动（反射向量扰动法）**
这是更常见和推荐的方法，思想是使用噪声法线去“弯曲”表面（由基础法线定义）的微观平面。

```glsl
// 假设我们有一个微表面中间向量 (Microsurface Midway Vector)
// 这里我们用噪声法线作为这个“扰动源”
vec3 m = noiseNormalTS; // 微观法线扰动源
float r = roughness * roughness; // 通常使用粗糙度的平方以符合感知

// 核心扰动操作：将基础法线朝向扰动源m“弯曲”
vec3 perturbedNormalTS = normalize(mix(normalTS, m, r));

// 或者，另一种更常见的工业实践（源自迪士尼原则渲染）：
// 对噪声法线进行缩放，然后用粗糙度控制其与基础法线的混合
vec3 noiseScaled = normalize(vec3(noiseNormalTS.xy * r, noiseNormalTS.z));
perturbedNormalTS = normalize(normalTS + noiseScaled);
```



使用可平铺的噪声法线纹理，可平铺的噪声纹理是一种**无缝连接**的纹理，当它被重复平铺时，边界处不会出现明显的接缝或重复图案。这是通过在生成过程中**保证周期性**来实现的。
