一、相关理论

1. 传统透明物体渲染方式：按照距离排序，从后往前渲染

2. 顺序无关透明

   - 核心思想：
     - 不排序
     - 按权重累加颜色和透明度

   - 缺点：只是视觉上差不多对，不追求物理正确

   - | OIT类型                  | 是否加权      | 是否排序     |
     | ------------------------ | ------------- | ------------ |
     | A-buffer / PPLL          | ❌             | ✔️（显式）    |
     | Depth Peeling            | ❌             | ✔️（多 pass） |
     | Moment OIT               | ✔️（统计矩）   | ❌            |
     | **Weighted Blended OIT** | ✔️（深度权重） | ❌            |

   - 顺序无关指的是不依赖Draw Call的提交顺序，而不是不能按照深度进行排序（A-Buffer / Depth Peeling 等）；

3. 深度剥离：逐层渲染，先渲染最远一层，依次重复N层，按层混合；需要N次渲染场景，层数不足时丢失细节；

4. A Buffer：使用每像素链表存储所有片元；
   1. 做法：
      - 每个像素维护一个链表
      - 所有透明片元写入
      - 最后排序 + 混合
   2. 优缺点
      - 理论最强
      - 显存、原子操作、实现复杂度极高

5. 加权混合OIT（Weighted OIT）
   - 不关心先后顺序，用深度计算权重，权重编码进Alpha，累加所有透明贡献；
   - 透明物体 fragment 使用MRT，计算片段颜色和revealage ；
   - 最终通过硬件Blend功能，按照Alpha混合颜色；

6. 叠加透明Fog ，Fog 其实是“参与透明叠加的体积层”

   -  `Weighted OIT revealage` **,**在忽略顺序的前提下，对“背景还能看到多少”的最优统计近似。**作为剩余可见度，可以自然扩展为 fog transmissivity**
   - Fog 可以当作 **α 连续分布的透明层**
