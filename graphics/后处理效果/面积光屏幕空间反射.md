1. PBR BRDF光照模型

   - NDF ：

   - Geometry 自遮挡：粗糙度对微表面自阴影

     - 粗糙度：当表面非常粗糙时，微表面起伏较大，自遮挡现象更明显，几何项的值会变小。
     - nov\nol项：当视线或光线与法线夹角越大（即NoL或NoV越小），自遮挡的可能性越大，几何项的值也会变小。
       - **阴影（Shadowing）**：从光源方向照射时，微表面之间相互遮挡，导致一部分光线无法到达表面点。
       - **遮蔽（Masking）**：从视线方向观察时，微表面之间相互遮挡，导致一部分反射光无法进入眼睛。

   - 菲涅尔项：计算反射、折射比率；返回高光反射比率；

     ```glsl
     // hov：半程向量与视线点乘
     float fresSchlickSmith( float HoV, float f0 )
     {
     	return f0 + ( 1.0 - f0 ) * pow( 1.0 - HoV, 5.0 );
     }
     ```

     - 计算的是**单次表面交互中，光能被反射的百分比（比率）**，这个值称为 **菲涅尔反射率 `F`**。
       - **返回值 `F` 的含义**：表示入射光中，有多少比例的光按照镜面反射方向（即完美反射方向）被反射出去。这是BRDF中**镜面反射/高光部分**的能量。
       - **对应的折射/透射部分**：根据能量守恒，剩余的光能 `1 - F` 会进入物体内部，形成**折射、散射（次表面散射）或被吸收**，最终体现为BRDF中的**漫反射部分**。
     - 返回值的范围是 **`[f0, 1.0]`**。
       - **`f0` (基础反射率)**：这是光线垂直入射（即法线方向，`HoV = 1.0`）时的反射率。它是一个介于 `0.0` 到 `1.0` 之间的值（或RGB向量）。
         - 对于**非金属（电介质）**，如塑料、木头、水，`f0` 很小，通常在 `0.02~0.05` 左右（例如，`vec3(0.04)`）。
         - 对于**金属（导体）**，`f0` 很高，并且具有颜色（RGB值），例如金是淡黄色，铜是红色。
       - **`1.0`**：这是光线以**掠射角**入射（即视线几乎与表面平行，`HoV ≈ 0.0`）时的反射率。**任何材质在掠射角下都会接近100%反射**，这是菲涅尔现象的核心特征。
