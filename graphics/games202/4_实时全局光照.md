# 全局光照

1. 全局光照
   - 直接光照
   - 间接光照
2. Reflective Shadow Maps(RSM)
   - RSM实际上存储了深度、世界坐标、法线、Flux、etc.
   - 认为Shadow Map上的色斑是次级光源；
   - 假设次级光源都是diffuse的，为什么？
   - 次级光源如何照亮其他物体
   - 缺点是：有多少光源就得做多少RSM
3. 辐射度量学
   - 单位立体角上能量有多少：Radiant Intensity
   - 在单位面积上的能量：Irradiance
   - 单位面积单位立体角的能量：Radiance 
4. Light Propagation Volumes（LPV）
   -  把整个场景分割为体素，体素中存储光线传播方向；
5. 屏幕空间相关技术
   1. SSAO (Screen Space Ambient Occlusion)
      - 目的：犄角处阴影，增加视觉真实感

   2. HBAO(Horizon Based Ambient Occlusion)
   3. SSDO(Screen Space Directional Occlusion)
   4. SSR(Screen Space Reflection/"RayTracing")
      - 在实时渲染中进行全局光照计算
      - 假设需要反射的绝大部分都是屏幕空间已渲染出来的物体；
      - 实质：在屏幕空间做光线追踪，不需要3D图元
      - 两个基础
        - 求交：射线和场景
        - 着色：交点像素对着色点的贡献
