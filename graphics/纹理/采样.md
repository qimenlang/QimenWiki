1. 采样原理 ：采样由屏幕像素覆盖多少纹素决定，采样函数根据UV在屏幕上的变化率，估算其覆盖纹理的面积，对该面积做过滤采样；

2. MIN_FILTER 与 MAG_FILTER 的区别

   两者的触发条件不同，本质上是看纹素 (texel) 与屏幕像素 (pixel) 的大小关系：

     ┌───────────────────────┬───────────────────────────────────┬──────────────────────────┐
     │        过滤器         │             触发条件              │         直观理解         │
     ├───────────────────────┼───────────────────────────────────┼──────────────────────────┤
     │ GL_TEXTURE_MAG_FILTER │ 1 个纹素 > 1 个像素（纹理被放大） │ 离物体很近，贴图被拉伸   │
     ├───────────────────────┼───────────────────────────────────┼──────────────────────────┤
     │ GL_TEXTURE_MIN_FILTER │ 1 个纹素 < 1 个像素（纹理被缩小） │ 物体远离相机，贴图被压缩 │
     └───────────────────────┴───────────────────────────────────┴──────────────────────────┘

   ---

     MAG_FILTER 可选值（只有 2 个，因为放大不需要 mipmap）

     - GL_NEAREST：取最近的那个纹素。效果：像素化、马赛克感，棱角锐利（适合像素风、UI 图标）。
     - GL_LINEAR：对周围 4 个纹素做双线性插值。效果：平滑、模糊，无锯齿但近距离会糊。

   ---

     MIN_FILTER 可选值（6 个，关键在 mipmap）

     缩小时一个像素覆盖了很多纹素，如果只采 1 个点会严重走样、闪烁（远处草地、栅栏抖动就是典型现象）。Mipmap        
     是预先生成的逐级缩小的纹理金字塔，按距离选合适的层。

     ┌───────────────────────────┬─────────────┬──────────┬────────────────────────────┐
     │           模式            │  层间策略   │ 层内策略 │            效果            │
     ├───────────────────────────┼─────────────┼──────────┼────────────────────────────┤
     │ GL_NEAREST                │ 不用 mipmap │ 最近邻   │ 最快，远处闪烁、锯齿严重   │
     ├───────────────────────────┼─────────────┼──────────┼────────────────────────────┤
     │ GL_LINEAR                 │ 不用 mipmap │ 双线性   │ 远处仍闪烁，因为单层不够   │
     ├───────────────────────────┼─────────────┼──────────┼────────────────────────────┤
     │ GL_NEAREST_MIPMAP_NEAREST │ 选最近层    │ 最近邻   │ 能看到 mipmap 层级间断带   │
     ├───────────────────────────┼─────────────┼──────────┼────────────────────────────┤
     │ GL_LINEAR_MIPMAP_NEAREST  │ 选最近层    │ 双线性   │ 层内平滑，但层间仍有跳变   │
     ├───────────────────────────┼─────────────┼──────────┼────────────────────────────┤
     │ GL_NEAREST_MIPMAP_LINEAR  │ 两层插值    │ 最近邻   │ 层间过渡平滑，层内仍像素化 │
     ├───────────────────────────┼─────────────┼──────────┼────────────────────────────┤
     │ GL_LINEAR_MIPMAP_LINEAR   │ 两层插值    │ 双线性   │ 三线性过滤，最平滑也最贵   │
     └───────────────────────────┴─────────────┴──────────┴────────────────────────────┘

   ---

     你代码里的设置含义

     GL_TEXTURE_MIN_FILTER = GL_LINEAR_MIPMAP_LINEAR  // 缩小：三线性过滤
     GL_TEXTURE_MAG_FILTER = GL_LINEAR                // 放大：双线性

     这是最常见的高质量默认配置：远处用 mipmap 三线性消除闪烁，近处用双线性避免马赛克。代价是显存增加 ~33%（mipmap  
     链）和一次额外采样。

   ---

     实践建议

     - 必须先调用 glGenerateMipmap(GL_TEXTURE_2D) 或上传所有层级，否则 MIN_FILTER 用 mipmap
       模式会得到黑色/未定义结果。
     - 如果还想消除斜视角下的拉伸模糊，进一步开启各向异性过滤 GL_TEXTURE_MAX_ANISOTROPY_EXT，效果远好于三线性。     
     - 海面这种高频法线/反射贴图（你正在看的 TritonDrawable.cpp 场景），三线性 +
       各向异性几乎是必选项，否则掠射角下波纹会剧烈闪烁。
