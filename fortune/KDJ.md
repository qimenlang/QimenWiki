# 一、KDJ —— 超买超卖指标（摆动指标）

## 1、本质是什么？

KDJ反映的是：

> **当前价格，在最近一段时间价格区间中的相对位置。**

举个例子：

最近9天

```
最高价：100
最低价：80

今天收盘：98
```

说明今天已经接近最近最高价。

如果今天收盘：

```
82
```

说明接近最低价。

KDJ就是把这个位置量化。

------

## 2、计算思想

第一步计算

RSV（Raw Stochastic Value）

公式思想：

```
RSV =
（今天收盘价－最近N天最低价）
-------------------------------- ×100
（最近N天最高价－最近N天最低价）
```

结果一定是

```
0~100
```

例如：

```
最高100
最低80

今天90

RSV=(90-80)/(100-80)=50
```

说明价格位于区间中间。

------

然后不断平滑得到：

```
K
D
```

最后

```
J = 3K - 2D
```

因此：

```
K
D
J
```

三条线。

------

## 3、怎么看？

通常软件里长这样：

```
100
|
|        J
|      /
|    K
|   /
| D
|
0
```

一般：

K：

> 快线

D：

> 慢线

J：

> 最敏感

------

## 4、经典判断

### （1）超买

```
K>80
```

很多人认为：

> 买的人太多了。

可能上涨快结束。

不是一定跌。

只是：

上涨已经比较充分。

------

### （2）超卖

```
K<20
```

说明：

卖压很重。

有可能反弹。

不是一定涨。

------

### （3）金叉

```
K
↑
穿过 D
```

例如：

```
K /

D /
```

变成

```
K \
  \
D  \
```

叫：

金叉

意味着：

上涨动能增强。

------

### （4）死叉

反过来：

```
K

D
```

K跌破D。

说明：

下跌动能增强。

------

## 5、KDJ最大的优点

非常灵敏。

适合：

- 短线
- 波段
- 震荡行情

------

## 6、最大缺点

容易骗人。

例如：

牛市：

```
一直80以上
```

它一直告诉你：

"超买了"

结果：

股票继续涨。

因此：

**KDJ不能单独使用。**
