#### transparent pass 锯齿问题

1. 问题描述：transparent pass 渲染输出的透明物体有明显锯齿，camera attach了color buffer和从opaque pass拿到的depth buffer；
2. 原因：Transparent Pass  Attach了外部depth,与内部的color的sample num不一致 ：1x depth（来自 gbuffer）\+ 8x color（transparent），二者sample数不一致，规则上不允许，导致FBO不完整；
3. 解决方案
   1. 尝试增加msaa，在attach color buffer时开启msaa，depth buffer msaa关闭，直接黑屏；
   2. 保持msaa 开启，clear depth buffer之后，可以消除锯齿，但深度测试全过，出现遮挡问题；
   3. color buffer保持msaa打开，depth buffer msaa关闭，两个buffer msaa num不一致，FBO 进入 INCOMPLETE_MULTISAMPLE或未定义行为，导致黑屏；如何验证INCOMPLETE_MULTISAMPLE？
   4. 针对Transparent Pass再增加FXAA Pass？
4. 相关概念：
   - attach(color buffer)指定msaa >0;  传入的color buffer是1x单样本的GL_TEXTURE_2D，在osg内部创建一个临时的msaa num GL_TEXTURE_2D_MULTISAMPLE,在前向渲染的光栅化阶段，进行msaa抗锯齿，最终结果解算到单样本GL_TEXTURE_2D；得到的是半物理正确的边缘 coverage 抗锯齿，不是 per-sample shading 抗锯齿；
   - 混合：基于覆盖率？
   - msaa：基于覆盖率、每采样点？
