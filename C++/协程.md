# 协程

#### 定义

1. 是一种可以暂停执行并恢复的函数，函数定义中有co_await、co_yield、co_return则是协程；没有函数栈；
2. 可以通过返回给调用者来暂停执行，恢复执行所需的数据和栈是分开存储的；
3. 允许顺序代码以异步的方式执行，支持惰性计算的无限序列；
4. 支持没有显式回调的情况下处理非阻塞IO；

#### 限制

1. 不能使用可变参数、普通的return、占位符返回类型（auto、Concept）
2. Consteval函数、constexpr函数、构造函数、析构函数、main函数不能是协程

#### 关联对象

1. Promise对象，在协程内部保存操作结果或异常；
2. 协程句柄，用于在协程外部，恢复协程执行或者销毁协程等；
3. 协程状态：内部的、动态分配的存储，包含：
   - Promise对象
   - 参数（按值复制）
   - 暂停点信息
   - 生命周期跨越当前暂停点的局部变量和临时变量；

#### 执行

1. operator new 分配协程状态
2. 将所有协程参数复制到协程：按值参数被移动或复制，按引用参数还是引用
3. 调用promise对象的构造函数；
4. 调用promise.get_return_object()并将结果保存在局部变量中。首次暂停时，结果返回给调用者；
5. 调用promise.initial_suspend()并`co_await`其结果。返回std::suspend_always(用于惰性启动的协程)，返回std::suspend_never(用于急切启动的协程)；
6. co_await promise.initial_suspend()恢复时，开始执行协程的主体；

#### 实现

1. ##### co_await - 暂停与恢复执行

   - 作用：用于暂停协程的执行，等待某个操作完成后再恢复
   - 场景：异步I/O、网络请求、定时操作

1. **co_yield - 生成值并暂停**
   - 用于生成器协程，产生一个值并暂停，稍后可以从暂停点继续执行
   - 场景：生成器、序列生成、流处理
2. **co_return - 协程返回**
   - 用于从协程返回值并结束协程执行
   - 场景：最终结果返回、协程终止
