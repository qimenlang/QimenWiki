允许函数模板将其参数以及参数的左右值属性完整地转发给其他函数。

## 核心概念

完美转发解决了以下问题：

- 保持参数的左值/右值属性
- 保持参数的 const/volatile 属性
- 避免不必要的拷贝操作

## 实现原理

完美转发依赖于两个C++11特性：

1. **通用引用（Universal Reference）**：`T&&` 参数可以根据传入实参自动推导为左值引用或右值引用
2. **引用折叠规则**：
   - `T& &` → `T&`
   - `T& &&` → `T&`
   - `T&& &` → `T&`
   - `T&& &&` → `T&&`

## 实际应用示例

```c++
#include <iostream>
#include <vector>
#include <string>

class Widget {
public:
    // 构造函数使用完美转发
    template<typename T>
    Widget(T&& name) : name_(std::forward<T>(name)) {}
    
    void print() const {
        std::cout << "Widget: " << name_ << std::endl;
    }

private:
    std::string name_;
};

// 工厂函数使用完美转发
template<typename T, typename... Args>
T create(Args&&... args) {
    return T(std::forward<Args>(args)...);
}

int main() {
    std::string name = "MyWidget";
    
    // 传递左值
    Widget w1(name);
    w1.print();
    
    // 传递右值
    Widget w2(create<std::string>("Temporary"));
    w2.print();
    
    // 使用工厂函数
    auto w3 = create<Widget>("FactoryCreated");
    w3.print();
    
    return 0;
}
```

#### 	可变参数模板的完美转发

```c++
#include <iostream>

// 目标函数
void target() {
    std::cout << "无参数调用" << std::endl;
}

template<typename T, typename... Args>
void target(T&& first, Args&&... args) {
    std::cout << "参数: " << std::forward<T>(first) << std::endl;
    target(std::forward<Args>(args)...);
}

// 转发函数
template<typename... Args>
void forward(Args&&... args) {
    target(std::forward<Args>(args)...);
}

int main() {
    forward(1, 2.5, "hello", 'a');
    return 0;
}
```
