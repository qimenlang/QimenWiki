### 1. Auto 类型推导 (`auto`)
**用途**：让编译器在编译期自动推导变量的类型。
**好处**：简化冗长的类型声明，特别是在模板和迭代器场景下，使代码更清晰，也更易于维护。
**示例**：
```cpp
std::vector<std::string> names = {"Alice", "Bob", "Charlie"};
// 无需写出冗长的迭代器类型
for(auto it = names.begin(); it != names.end(); ++it) {
    std::cout << *it << std::endl;
}

// 与范围for循环结合使用更是绝配
for(const auto& name : names) {
    std::cout << name << std::endl;
}
```

### 2. 基于范围的 For 循环 (Range-based for loop)
**用途**：提供一种简洁的方法来遍历容器（或任何有`begin()`和`end()`方法的对象）中的所有元素。
**好处**：消除循环变量和边界检查的样板代码，避免“off-by-one”错误，代码意图一目了然。
**示例**：
```cpp
std::vector<int> vec = {1, 2, 3, 4, 5};
for(int value : vec) { // 拷贝元素
    std::cout << value << " ";
}
for(const auto& value : vec) { // 常引用，避免拷贝
    std::cout << value << " ";
}
```

### 3. 智能指针 (`std::unique_ptr`, `std::shared_ptr`)
**用途**：自动管理动态分配的内存，防止内存泄漏。
- `std::unique_ptr`：独占所有权，轻量高效，替代`auto_ptr`。
- `std::shared_ptr`：共享所有权，使用引用计数。
**好处**：几乎完全消除了手动`new`/`delete`的需要，是现代C++管理资源生命周期的核心。
**示例**：
```cpp
// 无需手动delete
std::unique_ptr<MyClass> ptr = std::make_unique<MyClass>(args);
std::shared_ptr<MyClass> sharedPtr = std::make_shared<MyClass>(args);

// 当ptr超出作用域时，内存会自动释放
```

### 4. Lambda 表达式
**用途**：在调用的地方就地定义匿名函数对象。
**好处**：极大地简化了标准算法库（如`std::sort`, `std::for_each`）的使用，使得在函数中传递自定义操作变得非常方便。
**示例**：
```cpp
std::vector<int> vec = {5, 3, 1, 4, 2};
// 使用lambda表达式作为比较函数进行排序
std::sort(vec.begin(), vec.end(), [](int a, int b) { return a > b; });

// 捕获外部变量
int threshold = 3;
std::for_each(vec.begin(), vec.end(), [threshold](int x) {
    if(x > threshold) std::cout << x << " ";
});
```

### 5. 右值引用和移动语义 (`&&`, `std::move`)
**用途**：允许资源（如动态内存）从一个对象“移动”到另一个对象，而不是昂贵的拷贝。
**好处**：可以大幅提升性能，特别是对于管理大量资源的对象（如`std::vector`, `std::string`），实现了“转移所有权”而非“复制内容”。
**示例**：
```cpp
std::string str1 = "Hello";
std::string str2 = "World";
// 移动构造，str1的内容被“转移”到str3，之后str1处于有效但未定义的状态
std::string str3 = std::move(str1);

// 在函数中利用移动语义优化
void processString(std::string&& str) {
    // 高效地使用str，因为我们知道它是一个临时对象（右值）
}
```

### 6. 初始化列表 (`std::initializer_list`)
**用途**：允许使用花括号`{}`统一初始化各种对象。
**好处**：提供了一种清晰、一致且安全的初始化方式，可以用于初始化标量、数组、STL容器和自定义类。
**示例**：
```cpp
// 初始化各种类型
int arr[] = {1, 2, 3, 4, 5};
std::vector<std::string> cities = {"London", "Berlin", "Tokyo"};
std::pair<int, double> p = {42, 3.14};

// 也可以用于自定义类
class MyData {
public:
    MyData(std::initializer_list<int> args) { ... }
};
MyData data = {1, 2, 3, 4, 5};
```

### 7. 空指针常量 (`nullptr`)
**用途**：替代NULL宏，表示空指针。
**好处**：解决了NULL在重载函数中可能引起的歧义（NULL在C++中通常被定义为0，导致编译器可能选择`int`版本的重载而非指针版本）。
**示例**：
```cpp
void func(int);
void func(char*);

func(NULL);   // 可能会调用func(int)，不符合直觉
func(nullptr); // 明确调用func(char*)
```

### 8. 强类型枚举 (`enum class`)
**用途**：定义作用域内、强类型的枚举。
**好处**：
1.  **作用域**：枚举值在其枚举类名的作用域内，不会污染外部命名空间。
2.  **类型安全**：不能隐式转换为整数，也不能与其它枚举类型比较，避免了无意义的操作。
**示例**：
```cpp
enum class Color { Red, Green, Blue };
enum class TrafficLight { Red, Yellow, Green };

Color c = Color::Red; // 必须使用作用域运算符::
// int x = c; // 错误！不能隐式转换
int x = static_cast<int>(c); // 正确，需要显式转换

// if (c == TrafficLight::Red) {} // 错误！类型不匹配
```

### 9. 委托构造和继承构造
-   **委托构造**：一个类的构造函数可以调用同一个类的另一个构造函数。
-   **继承构造**：使用`using Base::Base`来让派生类继承基类的所有构造函数。
**好处**：避免了构造函数中的代码重复，使代码更简洁、更易维护。
**示例**：
```cpp
// 委托构造
class MyClass {
    int a, b;
public:
    MyClass(int x) : a(x), b(0) {}
    MyClass() : MyClass(0) {} // 委托给MyClass(int)
};

// 继承构造
class Base {
public:
    Base(int);
    Base(double);
};
class Derived : public Base {
public:
    using Base::Base; // 继承Base的构造函数 (Derived(int), Derived(double))
    // ... 可以添加Derived自己的成员
};
```

### 10. `std::optional` (C++17)
**用途**：表示一个“可能存在的值”。它是一个模板类，可以包含一个类型的值，也可以不包含任何值（表示为`std::nullopt`）。
**好处**：为“没有值”或“操作失败”的情况提供了比使用特殊值（如-1、nullptr）、`bool`返回值或抛出异常更清晰、更安全的选择。常用于函数返回值。
**示例**：
```cpp
#include <optional>

std::optional<int> findInArray(const std::vector<int>& data, int target) {
    for (auto val : data) {
        if (val == target) return val; // 找到了，返回包含值的optional
    }
    return std::nullopt; // 没找到，返回空的optional
}

// 调用者可以清晰地检查
auto result = findInArray(myVec, 42);
if (result.has_value()) { // 或 if (result)
    std::cout << "Found: " << result.value() << std::endl;
} else {
    std::cout << "Not found" << std::endl;
}
// 或者使用value_or提供默认值
std::cout << result.value_or(-1) << std::endl;
```
