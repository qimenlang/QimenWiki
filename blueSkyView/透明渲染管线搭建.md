# Transparent Pass (T2) 合成机制总结

## 一、问题背景

当前渲染流程：

- Opaque Pass → 输出 scene color
- Transparent Pass (T2) → 单独渲染所有半透明物体
- Compositor → 将 T2 结果与 scene color 进行最终合成

核心问题围绕：

1. T2 pass 的输出语义是什么？
2. T2 是否把黑色背景混进去了？
3. 为什么出现 “alpha 被乘两次” 的错误？
4. T2 的结果是否可以作为一个整体再参与混合？
5. 正确的合成公式是什么？

---

# 二、T2 Pass 的数学本质

假设：
```

glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);

```
标准 alpha blending 公式：
```

Cout = Cs * As + Cd * (1 - As)
Aout = As + Ad * (1 - As)

```
当 T2 的 framebuffer 初始值为：
```

Cdst = (0,0,0)
Adst = 0

```
则：

> T2 的输出 = 所有透明物体 over 黑色背景 的结果

---

## T2 输出的真实语义

T2 最终得到：
```

Ct = Σ (Ci * αi * Π(1 - αj))
At = 1 - Π(1 - αi)

```
这等价于：

- `Ct` = **Premultiplied Color**
- `At` = **覆盖率 (Coverage Alpha)**

重要认知：

> Ct 不是物体本身颜色  
> Ct 是“透明物体对最终像素的能量贡献”

---

# 三、“黑色是否被混进去了？”

是的。

但：

- 黑色 = 0 能量
- 不会污染结果
- 前提是 alpha 被保留

黑色只是计算起点，并不会影响最终物理意义。

---

# 四、常见错误：Alpha 被乘两次

错误流程：
```

T2:
Ct = Cs * α
At = α

Compositor:
Cfinal = Ct * At + sceneColor * (1 - At)

```
导致：
```

Cfinal = Cs * α²

```
错误原因：

> 把 premultiplied color 当成 straight alpha 再混了一次

---

# 五、正确的两种实现方式

---

## ✅ 推荐方案（引擎通用做法）

### T2 使用 Premultiplied Alpha

T2 输出：
```

Ct = 已乘 alpha
At = coverage

```
### Compositor 正确公式：
```

finalColor = Ct + sceneColor * (1 - At);

```
⚠️ 不再乘 At

优点：

- 数学自洽
- 与 forward transparent 一致
- 与 OIT 兼容
- 可扩展

---

## ⚠️ 备选方案（不推荐）

让 T2 输出 straight alpha：
```

glBlendFunc(GL_ONE, GL_ONE_MINUS_SRC_ALPHA);

```
T2 输出：
```

Ct = 原始颜色
At = α

```
Compositor：
```

Cfinal = Ct * At + sceneColor * (1 - At);

```
问题：

- 易和其他 pass 冲突
- 语义不统一
- 不利于扩展

---

# 六、T2 是否可以作为一个整体再合成？

答案：

> 在以下条件下，完全可以。

条件：

1. 半透明物体已按深度排序（far → near）
2. 使用标准 over alpha blending
3. 所有透明物体都在 opaque 之后
4. 不存在 transparent ↔ opaque 交错遮挡

满足这些条件：
```

Transparent A over Transparent B over Scene

```
等价于：
```

T2_result over Scene

```
---

# 七、什么时候会出问题？

## 1️⃣ 排序错误

透明物体交叉或未正确排序。

## 2️⃣ 与 Opaque 交错

例如：
```

Transparent A
Opaque Wall
Transparent B

```
压缩为 T2 会丢失信息。

## 3️⃣ 非标准混合模型

如：

- Additive blending
- Weighted OIT
- Dual-source blending

此时 T2 不再等价于 “over black”。

---

# 八、核心知识点总结

### 1. Transparent Pass 本质

> T2 = Transparent over Black

---

### 2. 输出语义

- Ct = Premultiplied color
- At = Coverage alpha

---

### 3. Compositor 正确公式
```

final = Ct + sceneColor * (1 - At)

```
---

### 4. 最常见错误

> Premultiplied color 再乘 alpha 一次

---

### 5. 工程结论

- 使用 premultiplied alpha 是现代渲染的标准做法
- 颜色只能乘 alpha 一次
- 黑背景不是问题
- 丢失 alpha 才是问题
