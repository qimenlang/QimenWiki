# 七、如果是我设计直升机下洗，我会这样设计数据流

这是我认为比较符合物理，又适合实时计算的一种架构：

```text
                 Rotor
                   │
                   ▼
        Rotor Force Distribution
                   │
        （旋翼推力分布，可近似高斯或环形）
                   │
                   ▼
      Velocity Injection Pass
      （向 Velocity Field 注入速度）
                   │
         RG16F Velocity Texture
         vx                vy
                   │
      ┌────────────┼─────────────┐
      │            │             │
      ▼            ▼             ▼
Height Update   Foam Update   Particle Update
      │            │             │
  二维波动方程   speed/div/curl   Sample Velocity
      │            │             │
      ▼            ▼             ▼
 Ripple        Foam Mask     Spray/Mist
      └────────────┼─────────────┘
                   ▼
            Water Renderer
```

这里有一个值得注意的点：

**我不会把你图片中的"放射状条纹"当成泡沫纹理来画，而会把它看成速度场本身具有的不均匀性。**

换句话说，在 Velocity Injection 时，我就会加入**角度方向的随机调制**（例如低频噪声、多个喷流瓣、轻微旋转扰动），这样不同方向的速度大小天然不同。后续：

- Height Field 会产生不规则的波纹传播；
- Foam 会在高速区域自然变白；
- Spray 粒子会优先沿高速方向喷射；
- Mist 密度也会沿高速区域扩散。

**最终，你图片里的那些放射状亮条，就不再是一张"贴图"，而是速度场演化后所有效果共同产生的结果。**

这也是现代实时模拟相比传统程序纹理最大的优势：**驱动源只有一个——速度场，而视觉效果可以不断扩展。**
