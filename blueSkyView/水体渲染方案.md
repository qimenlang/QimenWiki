# 水体渲染

1. 菲涅尔反射：实现水面的**远看亮，近看透**

   - 掠射角：强反射，像镜子，反射部分更高
   - 垂直视角：更透明，看到水下，折射部分更高

2. 反射

   - 天空盒
   - 环境贴图IBL
     - diffuse、ambient、specular convolution
   - SSR 屏幕空间反射

3. 折射 ：可以看到水底

   - 对水底场景进行偏移采样
   - 相关技术：
     - 屏幕空间折射（grab pass）
     - 深度参与偏移

   ```glsl
   vec3 refractDir = refract(-viewDir, normal, 1.0 / 1.33);
   vec3 refraction = texture(sceneColor, uv_offset).rgb;
   ```

4. 吸收 Absorption

   - 水越深，光的吸收越多，颜色越深

   ```glsl
   float depth = getWaterDepth();
   vec3 waterColor = vec3(0.0, 0.3, 0.5);
   vec3 absorption = exp(-depth * waterColor);
   ```
