# 水体渲染

1. 菲涅尔反射：实现水面的**远看亮，近看透**,反射与折射的比率，取决于观察角度；

   - 掠射角：强反射，像镜子，反射部分更高
   - 垂直视角：更透明，看到水下，折射部分更高

   ```glsl
   // 水的折射率大约是1.33，F0 = ((n1-n2)/(n1+n2))^2 = 0.02
   float fresnel = pow(1.0 - dot(viewDir, normal), 5.0);
   fresnel = mix(0.02, 1.0, fresnel); // Schlick approximation
   ```

2. 反射

   - 天空盒
   - 环境贴图IBL
     - diffuse、ambient、specular convolution
   - SSR 屏幕空间反射
   - 漫反射：可以忽略，不做常规lambert

     - 水是透明介质，能量集中在反射和折射

3. 折射 ：可以看到水底

   - 对水底场景进行偏移采样
   - 相关技术：
     - 屏幕空间折射（grab pass）
     - 深度参与偏移

   ```glsl
   vec3 refractDir = refract(-viewDir, normal, 1.0 / 1.33);
   vec3 refraction = texture(sceneColor, uv_offset).rgb;
   ```

4. 吸收 Absorption

   - 水越深，光的吸收越多，颜色越深

   ```glsl
   float depth = getWaterDepth();
   vec3 waterColor = vec3(0.0, 0.3, 0.5);
   vec3 absorption = exp(-depth * waterColor);
   ```

5. **焦散**：光线经过波浪形水面汇聚或发散，在水底物体或水下其他表面形成明亮的网状亮纹。这是水最标志性的视觉特征之一，但计算开销较大，通常使用预计算的焦散贴图或光子映射来近似。

6. 法线扰动

   - 多尺度叠加的法线
     - 大尺度波浪
     - 中尺度波形
     - 小尺度涟漪

   - 叠加多层不同频率波浪
   - 按径向扰动
   - 放射方向扰动
   - 加入flow / curl noise  流动、涡流噪声

7. 高光

   - 水是光滑表面，高光很强
   - roughness = 0.02，根据公式由水的折射率1.33计算得到
   - 使用BRDF微表面反射

     - GGX
     - Roughness**波浪的粗糙度，来自波浪高度、法线变化**

8. 次表面散射：实现水的边缘发亮效果，尤其是浅水；
