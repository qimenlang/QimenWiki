## 整体方案：

1. 基础海面（Background Ocean）,范围(10m,1km），提供真实海浪背景

   - FFT Ocean
   - Gerstner cluster

2. Rotor Pressure area ,旋翼压力区，一个圆形压力场：

   - 模型：P(r) = exp(-r² / R²)
   - 作用：压低水面，产生径向向外水流

3. Rotor DownWash : 下洗气流

   - 作用：中心压低、外围波纹扩散，海面中心凹陷
   - 模型：H_downwash = -A * exp(-r²/R²)

4. Rotor Vortex Ring : 旋翼涡环

   - 作用：产生换装涡流
   - 模型：sin(kr - ωt) * exp(-r²)

5. Kelvin Wake：旋翼尾流

   - 作用：形成类似船尾波纹

   - 图形：

     ```
             helicopter
                  ▲
                  │
          \       │       /
           \      │      /
            \     │     /
             \    │    /
     ```

     

   - shader：wave = sin(k(x cosθ + y sinθ))

6. Spray / Mist/ Foam  : 碎浪、喷雾、泡沫

   - 作用：真实直升机悬停海面
   - 使用粒子，生成条件：curvature（曲率）、velocity > threshold

## 物理模拟

1. 基于**波动方程**：近距离水体
   - 波动方程离散化:通过高度场迭代计算波纹传播，适合需要交互（如雨滴、船行）的场景
   - **下洗气流的压力分布**作为外力项加到波动方程中
     - 下洗气流压力分布可以使用预计算纹理采样
2. **快速傅里叶变换FFT方法**：远距离水体，生成无限海洋波浪，适合大范围海面。
