### 整体架构

```
FFT Ocean (基础海浪)
      │
      │ 叠加
      ▼
Rotor Downwash Disturbance (直升机扰动)
      │
      ▼
Height Map / Displacement
      │
      ├─ Normal Map
      ├─ Foam Mask
      └─ Spray Particles
      │
      ▼
Ocean Rendering

直升机下洗 = 局部压力扰动 + 高频波 + 泡沫 + 喷溅
```



### 下洗效果波形控制

1. 控制参数：直升机位置、方向、机翼直径等
2. 下洗波形建模
   - 环形波、Kelvin wake、水雾（spray）、泡沫（foam）、湍流（turbulence）
   - 直升机下洗可以看成：**移动的压力源 + 湍流风场**，用三种方法组合建模
     - 环形压力区（Rotor Pressure Field):
     - 环形波传播（Rotor Ring Waves）：向外传播的环形波；
     - 高频扰动（Rotor Turbulence）：高频小波纹，加入perlin、curl等噪声；
