* CPU sort（慢）
* GPU sort（复杂）

👉 这里可以深入：

* depth peeling
* weighted blended OIT

👉 这是**面试高频亮点**

## 4️⃣ 数据驱动 / 可编辑系统（真正难点）

### 如果只是 slider：

👉 没价值

### 如果做到：

* graph / node（类似 Niagara / UE）
* timeline（随时间变化）
* 曲线控制（color/size over lifetime）
* 模块化（emitter / modifier）

👉 这才是：

> **引擎级工具链设计能力**

---

## 5️⃣ 与引擎系统耦合（很多人忽略）

粒子不是孤立的：

* 和 lighting（PBR / shadow）
* 和 physics（碰撞 / 风场）
* 和 animation（绑定骨骼）
* 和 camera（motion blur / DOF）

👉 难点：

> **跨系统数据同步 & 性能控制**

---

## 6️⃣ 大规模性能问题（真正体现资深）

当你做到：

* 10万粒子 → easy
* 100万粒子 →开始有挑战
* 1000万粒子 →系统设计问题

你要解决：

* memory layout（SoA vs AoS）
* cache friendly
* GPU/CPU sync
* 帧间稳定性

* 不需要排序
* 工业界常用
* 技术含金量高

👉 核心思想：

```glsl
accumColor += color * alpha
accumAlpha += alpha
finalColor = accumColor / accumAlpha
```

👉 你会学到：

* MRT
* blending equation
* 半透明渲染架构

---

### ⚠️ 为什么推荐OIT？

因为：

| 方案    | 难度 | 价值       |
| ------- | ---- | ---------- |
| CPU排序 | 低   | 低         |
| GPU排序 | 极高 | 高但不现实 |
| OIT     | 中   | ⭐⭐⭐⭐⭐      |
