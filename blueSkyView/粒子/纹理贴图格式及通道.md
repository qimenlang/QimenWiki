下面是**格式规范里“能存什么”**的简化表（jpg = jpeg，同一种格式）。

| 格式       | 能有的通道（文件里）                                         |
| :--------- | :----------------------------------------------------------- |
| PNG        | 灰度(L)、灰度+透明(LA)、RGB、RGBA；调色板图还可带简单透明    |
| JPEG / JPG | 只有 RGB（无标准 alpha）                                     |
| BMP        | 调色板 / 灰度 / RGB / 带 alpha 的 RGBA（常见 32 位） 等，视具体位深与文件 |
| TGA        | RGB、RGBA（带 alpha 很常见）；也有索引色等变体               |
| GIF        | 索引色 + 单色透明（无完整 alpha 渐变）                       |
| WebP       | RGB 或 RGBA（可带 alpha）                                    |
| TIFF       | 灰度、RGB、RGBA 等很多种（规格宽）                           |
| DDS        | 由内部 压缩格式 定（常见 RGB、RGBA、块压缩带 alpha）         |

一句话：要 LA / RGBA → 优先 PNG、TGA、WebP、BMP(32)、TIFF；JPEG 只有 RGB；GIF 不算真 RGBA。
